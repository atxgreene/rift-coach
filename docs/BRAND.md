# Macro Goblin Brand

## Positioning

**Macro Goblin** is a local League companion that keeps the player honest: objective timers, gold/CS pressure, item adaptation, and pattern reads — all from safe, visible data.

Tagline options:

- Tiny goblin. Big macro.
- The friendly gremlin yelling about dragon.
- Less tilt. More timers.

## Voice

Short, useful, lightly funny. The app should feel like a sharp duo partner, not a generic AI assistant.

Examples:

- "Dragon in 30. Spend first."
- "That fight is cursed. Stop taking it."
- "Gold is banked. Reset before the flip."

## Visual system

- Background: near-black navy / slate
- Accent: antique gold
- Signal: teal-blue glow
- Status: green/yellow/red only for state, not decoration
- Density: glanceable HUD, not a data dashboard
